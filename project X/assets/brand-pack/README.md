# WMPP brand pack

Current implementation sources:

- [Brand guide](WMPP_Brand_Pack.md): approved palette and usage rules.
- [Palette](WMPP_Palette.json): exclusive 24-colour list and placement-category mapping.
- [Power BI theme](WMPP_Theme.json): current importable theme.
- `design-system/`: active CSS tokens and components.
- `icons/`: deployed SVG variants, originals, licences and provenance.

Only the agreed colours may be used in current WMPP authored formatting. Existing logo artwork is preserved. Information badges keep their pale background using the approved Soft Amber. The report's smaller KPI icons, circular navigation, spacing and glow are retained.

`Mockups/`, `Proposed Pack/`, unmodified upstream icon originals and `WMPP_Theme_v0.json` are historical/reference assets, not active defaults. Do not apply their old palette to the current report. Mission Control is a separate styling scope.
